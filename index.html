코딩테스트를 위한 Python 기초 훈련

알고리즘적인 사고는 있는데 코드로 표현이 잘 안 된다면, 이 훈련이 도움이 됩니다.
각 카테고리의 빈출도와 중요도를 참고해 우선순위를 정해보세요.

카테고리 선택 — 별★ 개수가 많을수록 코딩테스트 빈출

훈련 방식 — 각 드릴마다 Level 1 → 4 순으로 진행하세요

Lv.1
개념 확인
보기에서 고르며 눈으로 익힙니다.
Lv.2
구조 파악
코드 블록을 올바른 순서로 배치합니다.
Lv.3
직접 입력
힌트 없이 빈칸에 정확한 문법을 타이핑합니다.
Lv.4
전체 작성
전체 코드를 처음부터 직접 작성합니다.
다른 카테고리로 바로 이동
